Harness local-llm-bench — an agent loop, not a prompt. Each model is handed a real working directory and a set of tools, then left to work: it reads files, writes files, runs commands, looks at screenshots, and decides when it is done. Nothing is scored from what the model says — the verdict comes from running the project's own test suite in the directory the model edited.
Ollama /api/chat tool calling, non-streaming · 32k context cap, sliding-window history · tools: list_dir, read_file, write_file, run_command, screenshot, done · each command in its own process group, 120s cap · 15-min per-request ceiling · 40-min / 250k-token leg budget · fresh fixture copy per attempt, no network
Machine Apple M4 Max, 128 GB unified · macOS · Ollama 0.32.9 (MLX engine for safetensors, llama.cpp for GGUF)
